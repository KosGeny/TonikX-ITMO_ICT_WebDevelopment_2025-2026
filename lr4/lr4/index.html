Документация к информационной системе птицефабрики

Информационная система птицефабрики - это веб-приложение для автоматизации управления производственными процессами на предприятии. Система предоставляет функционал для работы с данными о курах, клетках, сотрудниках, диетах и яйценоскости, а также генерирует аналитические отчёты.

Проект реализован по архитектуре клиент-сервер:
- Backend: Django + Django REST Framework + Djoser
- Frontend: Vue.js 3 + Vuetify 3

Система поддерживает ролевую модель доступа:
- Директор - доступ ко всей информации и возможностям + к аналитическим отчётам
- Сотрудник - Управление курами, клетками, диетами, породами.

Описание интерфейсов

Авторизация и профиль

  • Страница входа (/login) — форма аутентификации с валидацией
  • Страница регистрации (/register) — регистрация новых пользователей
  • Профиль пользователя (/profile) — редактирование личных данных и смена пароля

Дашборд

Универсальная панель управления, которая отображает доступные разделы в зависимости от роли пользователя.

Управление курами

  • Список кур (/hens) — отображение живых кур с возможностью просмотра деталей
  • Детали курицы (/hens/:id) — информация о курице, её текущем размещении и яйценоскости за последние 30 дней
  • Поселение курицы (/hen-cages) — форма размещения курицы в клетку с автоматическим выселением из предыдущей клетки

Управление клетками

  • Список клеток (/cages) — просмотр всех клеток с возможностью удаления
  • Детали клетки (/cages/:id) — информация о клетке и текущих курах в ней
  • Закрепление клетки (/employee-cages) — назначение клетки сотруднику
  • Текущие закрепления — таблица активных назначений с возможностью открепления

Управление персоналом

  • Список сотрудников (/employees) — просмотр и редактирование данных о сотрудниках
  • Трудоустройство (/employments) — просмотр всех записей о трудоустройстве, сгруппированных по сотрудникам
  • Новое трудоустройство (/employments/new) — форма создания нового договора с валидацией уникальности номера договора

Управление фермой

  • Породы (/breeds) — управление породами кур
  • Диеты (/diets) — управление рационами питания
  • Диеты по породам (/breed-diets) — назначение диет породам по сезонам

Яйценоскость

  • Запись за сегодня (/eggs/today) — форма ввода яйценоскости для выбранной курицы с автоматическим сохранением сегодняшней даты

Аналитические отчёты (только для директора)

  1. Яйценоскость по характеристикам — анализ продуктивности в зависимости от веса и возраста
  2. Цех с наибольшим количеством кур — определение цеха по заданной породе
  3. Средняя яйценоскость на работника — продуктивность сотрудников
  4. Распределение пород по цехам — структура поголовья
  5. Разница показателей пород — сравнение заявленной и фактической яйценоскости
  6. Ежемесячный отчёт — агрегированные данные по всем цехам и породам

Вывод

В ходе выполнения лабораторной работы была разработана полнофункциональная информационная система для птицефабрики, удовлетворяющая условию задачи.

Система обеспечивает разделение доступа к функционалу между различными категориями пользователей.

Было уделено внимание безопасности (аутентификация через токены, валидация данных, защита от несанкционированного доступа) и удобству использования (понятный интерфейс, валидация форм, информативные сообщения об ошибках).
